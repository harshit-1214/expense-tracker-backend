# alembic/ - database migrations

Alembic keeps the PostgreSQL schema in sync with the models in `app/models/`.
Each change to the tables is a small versioned script, so every environment
(your laptop, a teammate's laptop, production) can be brought to the same schema.

| File / folder    | Purpose                                                                   |
| ---------------- | ------------------------------------------------------------------------- |
| `env.py`         | Connects Alembic to the database from `.env` and to the app's models.     |
| `script.py.mako` | Template Alembic uses when it generates a new migration file.             |
| `versions/`      | The migration scripts themselves, applied in order.                       |

## Everyday commands

Run these from the project root (the folder that contains `alembic.ini`):

```bash
alembic upgrade head                               # apply all pending migrations
alembic revision --autogenerate -m "add x column"  # create a migration after changing a model
alembic downgrade -1                               # undo the most recent migration
alembic current                                    # show which migration the database is on
```

Always open and read an autogenerated migration before applying it.
